# SoftGrowTech_InteractiveForm
Interactive Form Validation project built using HTML, CSS, and JavaScript. Features responsive design, real-time input validation, email verification, password matching, phone number validation, and user-friendly error handling. Designed to improve user experience and form security.

# Interactive Form Validation
## Features

* Responsive and user-friendly design
* Full Name validation
* Email format validation
* Pakistani phone number validation
* Password strength verification
* Confirm password matching
* Error messages for invalid inputs
* Success message on successful registration

## Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)

## Learning Outcomes

This project demonstrates frontend development concepts such as form handling, client-side validation, DOM manipulation, event handling, and responsive UI design.

## Project Purpose

The project was developed as part of the SoftGrowTech Frontend Development Internship Task to strengthen skills in user input validation and interactive web application development.
